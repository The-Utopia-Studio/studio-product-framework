The Utopia Studio · Studio Product Framework

Solution architecture

Agent-native monorepo: apps orchestrate, packages compose, Effect fences money and inference, Convex is the control plane. Builder agents ship through a commit gate; runtime agents meter credits in sandboxes.

Flow

Committed build path

  • Icarus discovery → commit-v1 artifacts
  • App + Convex action orchestrate
  • Effect owns wallet / inference / delivery
  • Mutations persist; providers stay outside

Agents

Two kinds, never mixed

  • Builder: agents/ loops and skills
  • Runtime: sandboxed @studio/ai-runtime
  • Reviews: Rams + Greptile greploop

Non-negotiable

What cannot fail

  • Composition boundaries
  • Entitlements + webhooks
  • Money ledger + inference brokerage
